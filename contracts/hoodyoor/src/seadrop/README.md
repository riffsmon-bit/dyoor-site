# SeaDrop interface provenance

These interfaces and structs are selector-compatible Solidity 0.8.24 adaptations of
OpenSea's MIT-licensed SeaDrop 1.0 source at commit
`6ab8b2ce1da7a750301fa34eb60a2bb8b26aebc1`.

The corresponding upstream files in the repository's pinned `lib/seadrop` tree match that
commit byte-for-byte:

- `src/interfaces/INonFungibleSeaDropToken.sol`
- `src/interfaces/ISeaDropTokenContractMetadata.sol`
- `src/interfaces/ISeaDrop.sol`
- `src/lib/SeaDropStructs.sol`

Canonical SeaDrop 1.0 address used on Robinhood Chain:
`0x00005EA00Ac477B1030CE78506496e8C2dE24bf5`.
