# HoodYØØR 128×128 onchain art payload

This directory is generated by:

```bash
npm run generate:robinhood:onchain-art
npm run generate:robinhood:assignments
npm run generate:robinhood:gtd
npm run generate:robinhood:reroll-rules
```

It contains the immutable payload consumed by `HoodYOORPackedTraitStore`, not source
art intended for manual editing.

## Binary trait format

Each non-None trait is encoded as:

```text
uint8 colorGroupCount
repeat colorGroupCount times:
  uint8 red
  uint8 green
  uint8 blue
  uint16 rectangleCount (big-endian)
  repeat rectangleCount times:
    uint32 rectangle (big-endian)
```

The rectangle word uses four 7-bit fields:

```text
bits  0..6   x
bits  7..13  y
bits 14..20  width - 1
bits 21..27  height - 1
bits 28..31  reserved and required to be zero
```

Trait names and art are concatenated into `hoodyoor-onchain-art.bin`. The payload is
split every 24,000 bytes under `chunks/`; traits may cross a chunk boundary. The
store reconstructs logical slices with `EXTCODECOPY` before `PixelSVG` validates and
decodes them.

`hoodyoor-trait-records.bin` is a fixed-width deployment table. Each 17-byte record
contains layer (1), trait ID (2), name offset (4), name length (2), art offset (4),
and art length (4), all multi-byte values big-endian.

## Reroll compatibility payload

`hoodyoor-reroll-rules.bin` is the canonical deployment table consumed by
`HoodYOORTraitRules`. Each six-byte, big-endian record contains layer A (1), trait
ID A (2), layer B (1), and trait ID B (2). Endpoints and records are numerically
sorted, so the file is deterministic.

The generated table contains 329 unique incompatibilities: 323 retained catalog
pairs plus six rules preventing the same visible accessory in both accessory
slots. Its Keccak-256 / frozen rules hash is
`0x14a33149be765254e70441c4ba2674c662f5b3f746fb3ac8a717a4f49b47ab0f`.

## Initial assignment payload

`hoodyoor-initial-assignments.bin` contains 3,333 big-endian 18-byte `uint144`
records. Each record packs nine 16-bit trait IDs in render order. Every assignment
is unique, references committed art, obeys all cooldowns, and passes the frozen
compatibility registry. Its Keccak-256 / collection provenance hash is
`0x2b3049a8235d705dba39542b53990e584e3815e4e6a32efae6ecb810b8f506a3`.

## Combined paid-GTD payload

`hoodyoor-gtd-allowlist.bin` contains 333 fixed-width records: a 20-byte address and
a two-byte big-endian `maxMint`. It combines 133 Monad D.Y.O.O.R holders at one paid
mint each with 200 imported Robinhood top holders at three paid mints each. There are
currently no overlaps, for an aggregate allowance of 733. Its Keccak-256 is
`0xa422f0b2443dea9c6d3d23e8ec312df7912fab929830aa435ef114923a148b68`.

`hoodyoor-gtd-tree.json` is the canonical OpenZeppelin `StandardMerkleTree` dump.
The root is
`0x915e9b6ddcfe13a197ade8f6b776d37beb8ce2f766001e6579bd0601ffc5dd31`.
The accompanying manifest and CSV preserve each source, allowance, and proof.
